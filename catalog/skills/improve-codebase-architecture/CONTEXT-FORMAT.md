# Domain Context Format

Keep `CONTEXT.md` concise and domain-focused. Create it with this shape when it
does not already exist, or preserve the project's existing structure when it
does:

```md
# Domain Context

## Glossary

### Term

Plain-language meaning, important invariants, and its relationship to other
domain terms.
```

Add only terms that emerged from an accepted design decision. Prefer the
language used by domain experts over implementation class or function names.
